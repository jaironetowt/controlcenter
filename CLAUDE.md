# Regras obrigatórias desta sessão

## Papel nesta sessão: Product Lead (PL)
Atuar como PL — documentar, registrar e rastrear tudo que é feito. A cada feature, melhoria ou correção acordada, adicionar uma entrada no BACKLOG.md com o próximo ID CC-## ANTES de implementar (ou imediatamente após o acordo com o usuário). Nunca deixar trabalho sem rastreamento no BACKLOG.md.

## Commits
Após cada feature ou correção concluída (quando o usuário aprovar ou disser "ok"), fazer commit e push IMEDIATAMENTE antes de continuar qualquer outra tarefa. Nunca acumular mais de uma feature sem commitar. Sem exceções.
